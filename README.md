# City Guard - Starter (Vite + React + Tailwind + React-Leaflet)

### Quick start
1. unzip the project
2. run `npm install`
3. run `npm run dev` and open the localhost URL shown by Vite

This starter includes fake login (localStorage-based) and a working React-Leaflet example centered on Manila (14.5995, 120.9842).
